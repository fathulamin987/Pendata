Eksplorasi Data Iris#

Data understanding#

Data Understanding adalah salah satu tahap dalam proses data mining yang bertujuan untuk memahami data sebelum dianalisis lebih lanjut. Pada tahap ini, data diperiksa untuk mengetahui isi, struktur, dan kondisinya agar siap digunakan dalam proses berikutnya.

Pada Dataset Iris, Data Understanding dilakukan dengan melihat atribut petal, yaitu petal_length dan petal_width. Dari atribut tersebut dapat diamati pola, sebaran data, dan perbedaan antar spesies. Dengan memahami bagian petal ini, kita dapat mengetahui bagaimana ciri-ciri bunga Iris berbeda satu sama lain sebelum dilakukan proses analisis atau pemodelan.

Dataset Iris Flower#

Dataset Iris Flower merupakan dataset multivariat yang diperkenalkan oleh ahli statistika dan biologi Inggris, Ronald Fisher, pada tahun 1936. Dataset bunga Iris ini sangat terkenal di dunia Machine Learning dan sering digunakan untuk proses klasifikasi.

Dataset Iris Flower merupakan data terstruktur karena dinyatakan dalam bentuk tabel yang terdiri dari atribut (kolom) dan baris.

Dataset ini terdiri dari:#

  • 150 data

  • 5 atribut

Empat atribut bersifat numerik, yaitu:#

  • sepal_length

  • sepal_width

  • petal_length

  • petal_width

Satu atribut bersifat kategorikal, yaitu:#

  • species

Pada atribut species terdapat tiga kategori, yaitu:#

  • iris-setosa

  • iris-versicolor

  • iris-virginica

# Statistik deskriptif

import pandas as pd
from scipy import stats

df = pd.read_csv("IRIS.csv")

# Ambil hanya kolom numerik (tanpa species)
df_numeric = df.select_dtypes(include=['int64','float64'])

for col in df_numeric.columns:
    print("===== Statistik untuk", col, "=====")
    print("Jumlah Data      :", df[col].count())
    print("Rata-rata        :", df[col].mean())
    print("Nilai Minimum    :", df[col].min())
    print("Q1               :", df[col].quantile(0.25))
    print("Median (Q2)      :", df[col].quantile(0.5))
    print("Q3               :", df[col].quantile(0.75))
    print("Nilai Maximum    :", df[col].max())
    print("Kemencengan      :", round(df[col].skew(), 6))

    mode = stats.mode(df[col], keepdims=True)
    print("Modus            :", mode.mode[0], "dengan jumlah", mode.count[0])

    print("Standar Deviasi  :", round(df[col].std(), 6))
    print("Variansi         :", round(df[col].var(), 6))
    print("\n")

Gambar diatas menunjukkan langkah-langkah pengolahan data menggunakan aplikasi analisis data (seperti Orange). Diagram ini memperlihatkan bagaimana data dimasukkan, kemudian dipilih dan dianalisis, lalu ditampilkan dalam bentuk tabel dan grafik untuk memudahkan pemahaman hasilnya.

Penjelasannya:

  1. File : Tahap awal untuk memasukkan data ke dalam aplikasi, misalnya dari file Excel atau CSV.

  2. Select Columns : Di sini kita memilih kolom data yang ingin digunakan atau dianalisis.

  3. Rank : Bagian ini digunakan untuk mengetahui kolom mana yang paling penting atau berpengaruh dalam data.

  4. Pivot Table : Digunakan untuk meringkas data supaya lebih mudah dibaca, misalnya mengelompokkan data berdasarkan kategori tertentu.

  5. Feature Statistics : Menampilkan ringkasan angka penting dari data, seperti rata-rata, nilai tertinggi, dan nilai terendah, agar kita lebih memahami isi data.

  6. Data Table : Menampilkan semua data dalam bentuk tabel, sehingga bisa dilihat dan dicek secara langsung.

  7. Scatter Plot : Grafik titik yang digunakan untuk melihat hubungan antara dua data dan mencari pola.

  8. Box Plot : Grafik yang menunjukkan sebaran data, nilai tengah, dan apakah ada data yang terlalu jauh (outlier).

  9. Correlations : Digunakan untuk melihat seberapa kuat hubungan antar kolom data.

Gambar diatas menampilkan informasi tentang dataset Iris yang digunakan untuk analisis data.

Penjelasan sederhananya:

  • Dataset ini berisi 150 data bunga Iris.

  • Terdiri dari 3 jenis bunga, yaitu : ( Iris-setosa, Iris-versicolor, dan Iris-virginica ).

  • Memiliki 4 kolom pengukuran (fitur)

  • Keempat kolom tersebut bertipe angka (numeric).

  • Kolom “iris” adalah target (kelas) yang menunjukkan jenis bunganya.

  • Tidak ada data yang 0 (missing values).

Pada tahap diatas yaitu eksplorasi data awal dengan melihat seluruh isi dataset dalam bentuk tabel. Tujuannya adalah untuk memahami data sebelum dianalisis lebih lanjut. Kita bisa melihat jumlah data, nama-nama kolom, serta nilai pada setiap baris. Dari tampilan ini juga dapat dipastikan bahwa tidak ada data yang kosong dan semua nilai terlihat normal. Selain itu, kita bisa melihat jenis bunga (iris) pada setiap data beserta ukuran sepal dan petalnya. Tahap ini penting karena membantu kita mengenal dan memastikan data sudah benar sebelum membuat grafik atau melakukan analisis lanjutan.

Pada tahap ini kita melihat ringkasan statistik dari setiap kolom data. Di sini ditampilkan informasi seperti:

  • Mean : nilai rata-rata

  • Mode : nilai yang paling sering muncul

  • Median : nilai tengah

  • Min & Max : nilai terkecil dan terbesar

  • Dispersion : tingkat penyebaran data

  • Missing : jumlah data yang kosong (di sini tidak ada)

Selain itu, terlihat juga grafik kecil (histogram) yang menunjukkan sebaran data untuk tiap jenis bunga (warna biru, merah, hijau).

Pada tahapan diatas dilakukan visualisasi data menggunakan scatter plot untuk melihat hubungan antara panjang sepal dan lebar sepal. Setiap titik mewakili satu data bunga, dan warnanya menunjukkan jenis bunga yang berbeda. Dari grafik terlihat bahwa bunga Iris-setosa cenderung terpisah dari dua jenis lainnya, sedangkan Iris-versicolor dan Iris-virginica sebagian masih berdekatan. Tahap ini membantu kita melihat pola, perbedaan, dan hubungan antar data secara visual dengan lebih mudah.
