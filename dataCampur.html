Mengukur Jarak Campuran#

Data Understanding - Online Foods Datasets#

Online Foods merupakan dataset yang berisi informasi mengenai profil demografi dan perilaku pelanggan dalam layanan pemesanan makanan online. Dataset ini digunakan untuk menganalisis pola konsumsi berdasarkan faktor sosial-ekonomi. Dataset ini terdiri dari 388 data dan memiliki 13 atribut.

Dataset ini dapat diunduh melalui Kaggle pada link berikut: https://www.kaggle.com/datasets/sudarshan24byte/online-food-dataset

Tujuan utama dari penggunaan dataset ini adalah untuk mempraktikkan penghitungan kemiripan (similarity) antar pelanggan yang memiliki karakteristik data campuran (numerik dan kategorikal).

Dataset ini terdiri dari:

  • 388 data

  • 13 atribut

4 atribut bersifat numerik, yaitu:

  • Age: umur

  • Family size: jumlah anggota keluarga

  • latitude: Angka desimal (koordinat lintang).

  • longitude: Angka desimal (koordinat bujur).

Atribut bersifat Kategorikal (Kualitatif) Nominal (Tanpa Urutan) Kategori yang setara dan tidak memiliki tingkatan.

  • Gender: Male, Female.

  • Marital Status: Single, Married, Prefer not to say.

  • Occupation: Student, Employee, Self Employeed, House wife.

  • Pin code: Meskipun berupa angka, ini adalah Nominal karena fungsinya sebagai label lokasi (tidak bisa merata-ratakan kode pos).

  • Output: Yes, No (Keputusan memesan).

  • Unnamed: 12: Yes, No (Kolom tambahan).

Ordinal (Memiliki Urutan/Tingkatan) Kategori yang memiliki jenjang atau level tertentu.

  • Monthly Income: Memiliki urutan tingkat ekonomi

  • Educational Qualifications: Memiliki jenjang akademik

  • Feedback: Memiliki nilai rasa atau kepuasan (Positive vs Negative).

Atribut yang Digunakan dalam Perhitungan Jarak#

Atribut yang digunakan dipilih berdasarkan relevansinya terhadap karakteristik sosial-ekonomi pelanggan.

  1. Age (Numerik)
    Digunakan karena usia memengaruhi pola konsumsi.

  2. Gender (Kategorikal)
    Digunakan untuk melihat perbedaan preferensi berdasarkan jenis kelamin.

  3. Marital Status (Kategorikal)
    Digunakan karena status pernikahan dapat memengaruhi kebiasaan pemesanan.

  4. Occupation (Kategorikal)
    Digunakan untuk merepresentasikan latar belakang pekerjaan pelanggan.

  5. Monthly Income (Ordinal)
    Digunakan karena tingkat ekonomi berpengaruh terhadap daya beli.

  6. Educational Qualifications (Kategorikal)
    Digunakan untuk melihat pengaruh tingkat pendidikan.

  7. Family Size (Numerik)
    Digunakan karena jumlah anggota keluarga memengaruhi frekuensi dan jumlah pesanan.

Total atribut yang digunakan: 7 atribut

Atribut yang Tidak Digunakan#

  1. Latitude

  2. Longitude
    Tidak digunakan karena merupakan data lokasi geografis dan dapat menyebabkan bias jarak jika digabung dengan atribut demografi.

  3. Pin Code
    Tidak digunakan karena hanya menunjukkan wilayah administratif dan tidak mencerminkan karakteristik individu secara langsung.

  4. Output
    Tidak digunakan karena merupakan variabel target/respon.

  5. Feedback
    Tidak digunakan karena merupakan hasil evaluasi, bukan karakteristik awal pelanggan.

  6. Order Type
    Tidak digunakan karena termasuk variabel perilaku spesifik, bukan profil dasar pelanggan.

Kesimpulan Pemilihan Atribut#

Perhitungan jarak campuran dilakukan menggunakan 7 atribut yang mewakili profil demografi dan sosial ekonomi pelanggan, sehingga analisis lebih fokus dan tidak bias terhadap variabel lokasi atau variabel target.

Transformasi Atribut Sebelum Perhitungan Jarak#

Karena dataset memiliki tipe data campuran, maka diperlukan transformasi agar seluruh atribut dapat dihitung secara matematis.

1. Atribut Numerik

Atribut numerik:

  • Age

  • Family Size

Dilakukan normalisasi menggunakan Min-Max Scaling:

[ X’ = \frac{X - X_{min}}{X_{max} - X_{min}} ]

Tujuan normalisasi adalah menyamakan skala agar tidak ada atribut yang mendominasi.

2. Atribut Kategorikal (Nominal)

Atribut:

  • Gender

  • Marital Status

  • Occupation

  • Educational Qualifications

Ditranformasikan menggunakan label encoding.

Contoh:

Gender:

  • Male = 0

  • Female = 1

Marital Status:

  • Single = 0

  • Married = 1

  • Prefer not to say = 2

Occupation:

  • Student = 0

  • Employee = 1

  • Self Employed = 2

  • House wife = 3

Educational Qualifications:

  • Graduate = 0

  • Post Graduate = 1

  • PhD = 2

  • Uneducated = 3

Perhitungan jarak:

  • 0 jika sama

  • 1 jika berbeda

3. Atribut Ordinal

Atribut:

  • Monthly Income

Karena memiliki tingkatan, dilakukan pengkodean berdasarkan urutan:

  • No Income = 0

  • Below 25000 = 1

  • 25001 to 50000 = 2

  • More than 50000 = 3

Kemudian dinormalisasi:

[ r_i = \frac{rank_i - 1}{m - 1} ]

Perhitungan Jarak Campuran#

Rumus umum:

[ D(i,j) = \frac{\sum_{k=1}^{p} d_{ijk}}{p} ]

Dengan:

  • p = 7 atribut

  • d_{ijk} = jarak tiap atribut

Jarak Numerik

[ d_{num} = |x’_i - x’_j| ]

Jarak Kategorikal

[ d_{cat} = \begin{cases} 0, & jika sama \ 1, & jika berbeda \end{cases} ]

Jarak Ordinal

[ d_{ord} = |r_i - r_j| ]

Jarak Total

[ D(i,j) = \frac{d_{Age} + d_{FamilySize} + d_{Gender} + d_{MaritalStatus} + d_{Occupation} + d_{Education} + d_{Income}}{7} ]

Hasil akhirnya berupa matriks jarak berukuran 388 × 388 yang menunjukkan jarak antar seluruh pasangan data dalam dataset.

Implematsi Menggunakan Orange#

Pada implementasi menggunakan Orange, diperoleh matriks jarak dengan dimensi 388 × 388.
